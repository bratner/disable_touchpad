# Icon attribution

The SVG files in this directory are copies of symbolic icons from the
[Adwaita icon theme](https://gitlab.gnome.org/GNOME/adwaita-icon-theme)
(GNOME Project):

| File | Adwaita source |
|------|----------------|
| `touchpad-enabled-symbolic.svg` | `symbolic/devices/input-touchpad-symbolic.svg` |
| `touchpad-disabled-symbolic.svg` | `symbolic/status/touchpad-disabled-symbolic.svg` |

When attributing the artwork, using "GNOME Project" is enough.
Please link to https://www.gnome.org where available.

At runtime the extension prefers the themed icon names
`input-touchpad-symbolic` and `touchpad-disabled-symbolic` from the
desktop icon theme; these files are shipped for packaging and fallback.
